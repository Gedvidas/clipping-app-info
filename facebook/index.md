# Clipping by Gedvidas — Facebook

A local application for uploading approved video clips to a Facebook Page you manage.

## How it works

1. Authorize the application and select your Facebook Page.
2. Select a local video.
3. Review the target Page and upload details.
4. Explicitly confirm the upload.
5. Check the processing status.

The default upload state is DRAFT. Public publishing requires explicit confirmation.

## Availability

The Meta application is currently unpublished.

The Page connection has been verified through a read-only API request. A real video upload has not yet been validated.
