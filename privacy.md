# Privacy Policy

Last updated: 24 October 2026

Clipping YouTube is an owner-operated desktop tool that uses
YouTube API Services to upload videos and manage the owner's
channel content.

## Data accessed and used

With your Google OAuth consent, the tool accesses channel IDs,
video and playlist information, metadata, visibility settings
and publication schedules. It sends selected video files,
thumbnails and metadata to YouTube to perform authorized actions.

The tool stores OAuth access and refresh tokens locally.
It does not request or store your Google password.

## Storage and sharing

Tokens, upload results and working files are stored in the
operator's local workspace. They must not be placed in the
public website repository.

Google processes API requests and uploaded content.
Only the owner and agents expressly authorized by the owner
may access private workflow data. When the owner uses an AI
assistant to operate the tool, command output and selected
workflow data may be processed by that assistant's provider.

Data is not sold or used for advertising.

## Retention and deletion

The operator must review stored YouTube API data and refresh
or delete it within 30 days, as required by YouTube's policies.

You may request deletion of locally stored tokens and API data
using the contact address below. The operator will complete
deletion as soon as possible and within seven calendar days.

These are operator responsibilities; the tool does not
currently provide automatic retention cleanup.

Deleting local data does not delete videos or other content
stored on YouTube. Manage that content through YouTube Studio.

## Revoking access

You can revoke the tool's access through
[Google account permissions](https://security.google.com/settings/security/permissions).

After revocation, the operator must stop using the authorization
and delete associated locally stored API data within seven days.

GitHub may process visitor information, including IP addresses,
as described in the
[GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

Google's handling of data is described in the
[Google Privacy Policy](https://policies.google.com/privacy).
